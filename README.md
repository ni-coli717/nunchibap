# 눈치밥 nunchi-bap · Streamlit

급식 대기 줄을 예측해서 5분 칸으로 나누는 학교용 서비스의 시연 앱입니다.
마송고등학교 모의창업 프로젝트 (박유건 · 이예니).

## 구성
- `app.py` — 학생 앱 (가입 → 사용법 → 예약 → 추천 → 확정 → 하교 후 피드백 → 기록 · 팀 · 정기 예약 · 설정)
- `pages/1_관리자.py` — 관리자 웹 (학교 설정 · 오늘 대시보드 · 운영 규칙 · 리포트)
- `pages/2_교실_배정표.py` — 교실 전자칠판 화면
- `nb_core.py` — 대기행렬 계산, 추천, 배식 속도 자동 보정, 저장
- `nb_ui.py` — 시간표 스타일 공용 UI
- `data/state.json` — 시연 데이터 (앱이 자동으로 만듭니다)

## 로컬 실행
```
pip install -r requirements.txt
streamlit run app.py
```

## 계산 원리
- 5분 칸 정원 = μ(명/분/라인) × 라인 수 × 5분 × 안전계수 0.85
- 예상 대기 = (앞선 누적 대기 인원 + 이 칸 도착 인원) ÷ (μ × 라인 수)
- 배식 속도 자동 보정: μ오늘 = 0.8·μ어제 + 0.2·μ추정 (하교 후 피드백의 대기 구간으로 추정)

발표 전 초기화: 관리자 → 학교 설정 → **시연 데이터 초기화**. 데이터는 서버 파일에 저장되므로 재배포하거나 앱이 잠들었다 깨면 초기화될 수 있습니다.
